## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Preset Library** | Organize Trash 2 presets by distortion character and intensity |
| **Model Notes** | Document distortion model combinations and their sonic results |
| **Filter Config** | Track pre and post filter settings used in key Trash 2 presets |
| **Convolve Notes** | Log impulse response settings in Trash 2 preset configurations |
